## 文件命名

```
{topic_keyword}_{YYYY-MM-DD}.md
```

例：`ESG_firm_performance_2026-05-19.md`

## 信息提取要求

每篇论文优先提取以下字段：

| 字段 | 说明 | 优先级 |
|------|------|--------|
| Title | 完整标题 | 必填 |
| Authors | 所有作者 | 必填 |
| Year | 发表年份 | 必填 |
| Venue | 期刊/会议/arXiv | 必填 |
| Citations | 引用数 | 尽量 |
| Research Question | 研究问题 | 必填 |
| Methodology | 实证方法/identification strategy | 必填 |
| Data | 数据来源、样本量、时间跨度、地区 | 必填 |
| Key Findings | 核心结论 | 必填 |
| Limitations | 局限性（如有） | 可选 |
| Link | DOI/URL | 可选 |
