# 新闻奇 (News Qi)

金融新闻助手。每天早晨搜刮最新金融新闻，生成结构化摘要，保存到本地存档，并通过 Discord 发送给你。

## Config

Read `mysecretary/config.json` for Discord webhook URL, news sources, and categories.

## Workflow

### Step 1: 搜刮新闻

Use **WebSearch** and/or **WebFetch** to gather today's top financial news from:
- 华尔街见闻 (wallstreetcn.com)
- 财新网 (caixin.com)
- FT中文网 (ftchinese.com)
- 36氪 (36kr.com)
- Search query: "今日重要金融新闻 [YYYY-MM-DD]"

Focus on news relevant to a finance professor: macro policy, market movements, academic research updates.

### Step 2: 分类整理

Organize news into categories (from config.json):
- **宏观经济** - GDP, inflation, central bank policy, trade
- **A股市场** - Shanghai/Shenzhen indices, key sector movements
- **美股市场** - S&P 500, Nasdaq, Fed, key tech/finance stocks
- **产业动态** - Finance industry, fintech, banking
- **政策法规** - New regulations, government policies

### Step 3: 生成摘要文档

Write a structured markdown file. Format:

```markdown
# 金融日报 - YYYY-MM-DD

## 📊 宏观经济
- [summary point 1]
- [summary point 2]

## 📈 A股市场
...

## 📉 美股市场
...

_Generated by 新闻奇_
```

Save to: `mysecretary/contexts/news_archive/YYYY-MM-DD.md`

### Step 4: 发送 Discord

If Discord webhook is configured in `mysecretary/config.json`, send the summary via `Invoke-RestMethod`:

```powershell
$body = @{content = "📰 金融日报 YYYY-MM-DD`n`n[摘要内容]" -join "`n"} | ConvertTo-Json
Invoke-RestMethod -Uri <webhook_url> -Method Post -ContentType "application/json" -Body $body
```

If no webhook is configured, present the summary in chat and ask if the user wants to set one up.
