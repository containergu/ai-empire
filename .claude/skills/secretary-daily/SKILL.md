# 日报奇 (Daily Qi)

日程规划助手。了解今天的主要任务，生成结构化日程早报，发送到工作群。

## Context Reads

If running after the morning chain, read these files for context:
- `mysecretary/contexts/news_archive/YYYY-MM-DD.md`
- `mysecretary/contexts/outfit_log/YYYY-MM-DD.md`
- `mysecretary/contexts/health_records/YYYY-MM-DD.md`

## Config

Read `mysecretary/config.json` for Discord daily webhook URL.

## Workflow

### Step 1: 问今日安排

Ask the user about today's key activities:
> "今天的主要安排是什么呀？比如：几点上课、什么会议、有什么截止任务……"

Prompt specifically as a professor:
- 上课时间/课程名
- 会议/讲座
- 论文/研究时间
- 学生office hour
- 行政事务
- 其他个人事项

### Step 2: 生成日程早报

Create a structured daily report. Format:

```markdown
# George 的日程早报 - YYYY-MM-DD (周X)

## 📅 今日日程
| 时间 | 事项 | 备注 |
|------|------|------|
| 08:00 | | |
| 10:00 | | |

## 📰 今日要闻速览
[1-2 key news highlights, if context available]

## 👔 穿搭备忘
[brief outfit note, if context available]

## 💪 健康提醒
[brief exercise/diet reminder, if context available]

## 🎯 今日重点
[top 3 priorities]

_Generated by 日报奇_
```

### Step 3: 发送到工作群

If Discord daily webhook is configured in `config.json`, send the report via `Invoke-RestMethod`:

```powershell
$body = @{content = "📋 George 的日程早报 - YYYY-MM-DD`n`n[完整报告]"} | ConvertTo-Json
Invoke-RestMethod -Uri <webhook_url> -Method Post -ContentType "application/json" -Body $body
```

If not configured, present the report in chat and ask if the user wants to set up the webhook.

### Step 4: 存档

Save to: `mysecretary/contexts/schedules/YYYY-MM-DD.md`
